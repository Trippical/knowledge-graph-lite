# Refund approvals

Tiered approval structure for refund processing:

| Band       | Path                                              |
| ---------- | ------------------------------------------------- |
| Under £500 | Support self-serve, completed within 48 hours     |
| Over £500  | Ops Manager sign-off before funds are disbursed   |

Approved refunds are paid back to the original payment method only.

During recorded Ops Manager leave, sign-offs follow the delegation cover —
see [ops-manager.md](ops-manager.md) § Delegation cover.
